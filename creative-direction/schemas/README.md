# Creative direction schemas

Canonical contracts for weekly generated outputs. Runtime validation uses Zod in [`src/lib/schemas/creative-direction.ts`](../../src/lib/schemas/creative-direction.ts).

- `creative-direction.schema.json` — strategy brief
- `theme.schema.json` — visual tokens
- `interaction-system.schema.json` — interaction behavior
- `signal-scout.schema.json` — step 1 research
- `visual-culture-analyst.schema.json` — step 2 interpretation
