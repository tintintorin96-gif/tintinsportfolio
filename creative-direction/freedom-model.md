# Design freedom model

| Zone | Freedom | Automation may change |
|------|---------|------------------------|
| Hero | 100% | Layout, type scale, effects, motion |
| Landing supporting sections | 60% | Bands, spacing, card chrome |
| Work grid | 30% | Light card/surface treatment |
| Navigation | 10% | Border, accent, subtle reveal only |
| Content | 0% | Never auto-rewrite copy |
| Case studies | 0% | Never auto-rewrite teasers |

Supporting sections must inherit the hero’s experience language. Navigation stays structurally stable.
