# Living Portfolio Agent

This is a Next.js portfolio that changes visual theme daily based on current design trends.

## Hard rules

- Never rewrite portfolio content automatically.
- Never remove case studies.
- Daily automation may only update:
  - `src/generated/theme.json`
  - `obsidian/design-trends/*.md`
- Keep accessibility and contrast.
- Preserve performance.
- Do not push directly to main unless running inside the scheduled GitHub Action.
- Run lint and build before committing.

## Design rules

- The site should feel professional, not gimmicky.
- Trends should be interpreted subtly.
- Content stays stable; visual system evolves.
- Prefer design tokens over component rewrites.

## Project layout

```
src/
  app/           Next.js App Router pages
  components/    Shared UI components
  generated/     Auto-generated artifacts (theme.json)
  lib/           Utilities (theme.ts)
scripts/         Build and generation scripts
obsidian/        Design notes and trend research
```

## Theme system

- Daily themes are generated by `scripts/generate-daily-theme.ts` and stored in `src/generated/theme.json`.
- Components consume tokens via `src/lib/theme.ts` — never hardcode colors or fonts.
- Design inspiration lives in `obsidian/design-trends/`; portfolio content in `obsidian/tintinportfolio/`.

## Cursor rules

- `.cursor/rules/portfolio-theme-agent.mdc` — theme generation workflow
- `.cursor/rules/accessibility.mdc` — WCAG AA standards
