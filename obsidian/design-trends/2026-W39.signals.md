## Dominant movement (analyst)

**Outline gravity.** Award sites this week stage work as a selection system — grid, list, or active field; hover that gives one piece weight while neighbors recede to architectural outline — rather than last week’s surveyed horizon, a drafting-sheet walk, or a WebGL cockpit.

## Recurring movements

- Same content, multiple viewing modes — choice as architecture, not a new dataset
- Hover as priority: the active object holds gravity; the rest remain as quiet structure
- Motion as a second design layer on a restrained visual system
- Scroll as a predictable timeline the visitor still controls
- Two-color restraint as the field that makes an outline readable

## Emerging signals

- **Choice as interface architecture** (interaction-system, shipped, recurring)
  - Why it matters: Architecture and motion-studio sites refuse a single fixed index. They let visitors change how they look at the same body of work — grid, list, active gallery — and they keep one mode deliberately simple so the others can be expressive.
  - Evidence: Codrops [Kononenko Architectural Bureau](https://tympanus.net/codrops/2026/09/18/kononenko-architectural-bureau/) (Sep 18, Artem Shcherban / Reksa Andhika) — Grid / List / Active Gallery; list kept simple as counterbalance. Codrops [House of Yellow](https://tympanus.net/codrops/2026/09/16/house-of-yellow/) (Sep 16) — visual grid vs informational list of the same collection.
  - Portfolio fit: Hero as a selection prologue, supporting page as quieter list-mode. Do not import the three-mode WebGL morph.

- **Hover that recedes neighbors to outline** (visual-system, shipped, emerging)
  - Why it matters: KNKO’s hover borrows architectural drawings without using drawings as decoration — the active project takes visual priority while surrounding works reduce to outlines and never fully disappear.
  - Evidence: KNKO Codrops (Sep 18) — hover as shared grammar across viewing modes; sketches become interface objects, not gallery wallpaper.
  - Portfolio fit: Typographic gravity in the hero — one line holds weight, supporting lines drop to outline stroke. Depth-reveal on teasers, not 3D unboxing.

- **Motion as a second design layer, interruptible** (motion-system, shipped, recurring)
  - Why it matters: The week’s strongest craft is not more animation. It is motion that transforms a restrained composition, stays interruptible (switch mid-morph, scroll during a transition), and remains quiet in sections that should stay simple.
  - Evidence: KNKO Codrops (Sep 18) — “the design remains restrained. The movement is allowed to break that restraint”; GSAP ticker shared with WebGL, every morph spammable. House of Yellow Codrops (Sep 16) — scroll as a timeline the visitor still controls; motion follows rather than fights.
  - Portfolio fit: One interruptible weight-to-outline thread in the hero. Instant last-frame under `prefers-reduced-motion`. No logo-as-spectacle, no marquee play-button clone.

- **Directed first-contact as process state** (ai-native, shipped, emerging)
  - Why it matters: AI-native contact is graduating from chat overlays to a role: qualify fit, reveal intent, show thinking as semantic state. Linear/Vercel agent sessions encode the same idea as thought → action → elicitation → response.
  - Evidence: [L.I.S.A.](https://www.awwwards.com/sites/l-i-s-a) (Awwwards SOTD Sep 16, Locomotive / 60fps) — conversational interface replacing a contact form; virtual assistant, microcopy, black/white. Linear [agent interaction](https://linear.app/developers/agent-interaction) — session states and typed activities, first thought within 10 seconds.
  - Portfolio fit: Process-state language for motion (loading as thought, complete as last frame). Do not add a talking contact widget.

- **Two-color kiln / outline fields** (visual-system, shipped, recurring)
  - Why it matters: After last week’s glacier vapor and horizon cyan, the field this week is greener, flatter, and more like drawing paper — kiln ash, kiln ink, one structural mark — still two-color, no cream editorial.
  - Evidence: [Aspen Search](https://www.awwwards.com/sites/aspen-search) (Awwwards SOTD Sep 15) — `#ffffff` / `#232323`, big type, boxy, Suisse, Next.js; extract type discipline, deprioritize confetti. [Pensatori Irrazionali](https://www.awwwards.com/sites/pensatori-irrazionali) (Awwwards SOTD Sep 20) — `#f5f5f5` / `#4c4c4c`, modular identity, interface as negotiation; extract quiet gray sheet, deprioritize WebGL universe. [Boc.Studio](https://www.awwwards.com/sites/boc-studio) (Awwwards SOTD Sep 19) — extract continuous-surface hover handoffs; reject `#FF4421` orange. [Noho](https://www.awwwards.com/sites/noho) (Awwwards SOTD Sep 18) — extract quiet idle layer and gallery scroll; reject cream `#F1EEE9` / `#E7E2DA`.
  - Portfolio fit: Kiln-ash plaster, kiln ink, one deep pine. Not W38 glacier + horizon cyan, not W37 zinc + blueprint, not orange, not cream.
