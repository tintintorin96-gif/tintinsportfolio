# AI-Native Products — Reference Lens

Use for **AI-native interface aesthetics** and emerging product interaction patterns.

## Sources

- Linear, Raycast, Arc Browser, Notion AI surfaces
- Emerging AI copilot and agent UIs
- Figma Community AI workflow patterns

## What to study

- How AI features are staged without overwhelming core tasks
- Typographic and spatial hierarchy for generative output
- Trust, latency, and state communication in AI flows
- Subtle motion for streaming / thinking / completion states

## Signal categories

- Interaction language for prompts, results, and undo
- Motion for progressive disclosure
- Visual systems that feel luxury-tech, not generic chat
- Creative technology opportunities (generative hero elements, adaptive layout)

## Weighting

Prefer shipped product patterns over concept mockups. Extract principles, not UI clones.

## Latest weekly research - 2026-W28

**Signal window:** 2026-06-29 - 2026-07-05

- AWS AgentCore and AG-UI coverage shows agent frontends moving beyond text streaming into generative UI, shared state, tool-call events, and human-in-the-loop pauses.
- CopilotKit's AG-UI framing makes the interface layer explicit: text deltas, tool-call starts/results, state deltas, lifecycle events, and multi-agent handoffs can be rendered as visible product states.
- Figma Community AI agent kits show the same product pattern from the design-system side: chat inputs, streaming states, suggestion chips, reasoning steps, plan/confirm, citations, onboarding, and dashboards.
- Portfolio fit: borrow the transparency principle through hero state rails and artifact panels. Avoid literal chat UI, reasoning-step chrome, or agent dashboards in the public portfolio.
