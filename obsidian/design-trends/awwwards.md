# Awwwards — Research Lens

Use for **shipped, award-caliber web experiences** — not static inspiration shots.

## What to study

- Site of the Day / Site of the Year winners and nominees
- FWA (Favourite Website Awards) winners
- CSS Design Awards, Site Inspire, Godly

## Signal categories

- **Visual systems:** typography scale, grid logic, color discipline, depth
- **Interaction systems:** scroll choreography, cursor behavior, navigation models
- **Motion systems:** page transitions, reveal timing, hover choreography
- **Creative technology:** WebGL layers, generative elements, real-time rendering

## Weighting

Prioritize live production sites over case-study stills. Note what is technically shipped vs. concept-only.

## Avoid

- Copying layouts or effects directly
- Treating one-off award stunts as recurring movements
- Surface-level “trend” labels without experience rationale
