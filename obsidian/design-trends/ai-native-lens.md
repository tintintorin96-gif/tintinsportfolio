# AI-Native Lens

Last updated: 2026-06-08
Week: 2026-W23

## Current movement

AI-native design is moving from static generation toward collaborative work surfaces. The meaningful product signal is not that an agent can create an image or layout; it is that teams can point at live UI, attach visual context, annotate exact regions, and carry the result into code, prototypes, dashboards, or hosted sites.

## Evidence this week

- OpenAI Codex introduced role-specific plugins and Sites on 2026-06-02, including product design workflows that can become interactive shared pages.
- Cursor Design Mode emphasizes spatial prompting through element selection, drawing, and voice, giving agents both code identity and page-state screenshots.
- CSSDA's Gucci - Mystery Unfolds signal pairs AI conversation with narrative game mechanics instead of using AI as decorative copy.

## Portfolio implication

- Express AI as clarity, agency, and collaboration.
- Use motifs like signal paths, annotated surfaces, layered context, and live-system calm.
- Keep content stable; the weekly system should not invent claims about case studies or services.

## Avoid

- Overstating autonomy.
- Robot imagery, glowing chat bubbles, and generic prompt windows.
- AI-generated texture that weakens accessibility or brand trust.
